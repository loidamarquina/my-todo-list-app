# My To-Do List Web App

## Author
Loida Marquina

## Overview
The My To-Do List Web App is a lightweight, responsive React application that allows users to create, view, update, and delete to-do items. The application also includes a contact form where users can submit personal information and comments.

The project demonstrates core concepts of React, controlled components, state management, routing, and CRUD operations.

## Features
- Add new to-dos
- Mark to-dos as completed
- Delete to-dos
- Filter to-dos by status:
  - All To-Dos
  - Completed
  - Incomplete
- Responsive UI with custom styling
- Contact form with controlled components

## Technologies Used
- HTML
- CSS
- JavaScript
- React
- React Router
- gh-pages

## Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/task-management-web-app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start local development server:
   ```bash
   npm start
   ```

## Deployment
This app is deployed using GitHub Pages with the `gh-pages` package.

Deployment commands:

```bash
npm run deploy
```
